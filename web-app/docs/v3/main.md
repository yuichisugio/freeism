## v3：新しい仕様

### v3：貢献評価を代用する仕組み

- 説明
  - 「貢献評価を代用する仕組み」を無料主義アプリで使用できるよう実装する

### v3：パブリックAPI

- 概要
  - 他のサービスから、無料主義アプリの情報にアクセスする手段を増やしたい

- APIの種類
  1.  ポイント付与
      - 説明
        - 無料主義アプリに入って、GUIからCSVアップロードが面倒なので、APIで操作する。
        - `curl`コマンドで操作したり、外部サービスとの連携でも使用する
      - 使用場面
        1.  付与の取り消し
        2.  新しくポイント付与
        3.  既存のポイント付与額の更新

### v3：エクスポート・インポート機能

- 説明
  - 無料主義アプリ内のすべての設定項目をエクスポート・インポートできる機能

- 実装したい理由
  1.  他者のオススメ設定を簡単に導入する
  2.  設定項目をコードとして管理したい
  3.  複数の無料主義アプリの競争を活性化させるために、無料主義アプリ全体の移行を簡単にしたい

- 要件
  1.  CSVアップロードに対応したい
      - CSVアップロードに対応する理由
        1.  JSON形式よりもユーザーが使い慣れているため
      - JSONアップロードに対応しない理由
        1.  JSONアップロードにも対応したいが、エンジニア以外はJSON形式が使い慣れていないのでCSVアップロードのみに対応したい
            - 今後、余裕ができたらJSONアップロードを検討する
  2.  一部アップデートの対応
      - 説明
        - 全部の項目を上書きせず、一部のプロパティのみ記載してアップロードして部分更新ができるようにしたい
      - その理由
        1.  全部の上書きは避けたい場合が多いため
  3.  インポート・エクスポート機能に対応する項目
      1. 評価軸の設定
         1. 名前
         2. 説明
         3. 設定URL
         4. 他の評価軸との交換比率
         5. アドミン権限のユーザーID
      2. パッケージの設定
         1. 名前
         2. 説明
         3. 設定URL
         4. 構成する評価軸の構成比率
         5. アドミン権限のユーザーID
