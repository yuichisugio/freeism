## 説明

- あらゆるアカウントのIDを統合して管理できるサービス

## 存在意義・独立したサービスにする理由

1. 無料主義の貢献度アップロードのアカウント管理を簡単にする
   - サービスの実装側・利用側の両方で、利用を簡単にしたい
2. アカウント統合の処理はとても複雑なので、責務の分離の為に切り出す
3. 他の無料主義サービスが、同じ内容を実装する必要がない状態にしたい
4. ポイント管理サービス以外からでも使用できると思う

## v0.1で実装する機能

1. アカウントのIDの表示
   - `accounts.freeism.app`内のユーザーIDを表示
2. Accountsへのログイン
   - v0.1では、Google OAuthのみをログイン手段にする
   - Googleアカウントを、Accounts内のユーザーを識別する基点にする
3. 外部アカウントの所有権証明
   1. GitHub OAuth
   2. bi-directional link
4. OAuth Provider
   - `points.freeism.app`から権限付与できるようにする
   - 今後は、複数の`accounts.freeism.app`のようなサービスから、どれかを選べるようにしたいのでOAuth Providerにする
5. 閲覧権限の制御
   - 誰に、どのデータの閲覧権限を渡してもよいのか
   - 連携したすべてのアカウントや情報を、それぞれのクライアントごとに公開するか決められるようにしたい
6. ドメインは、`accounts.freeism.app`
   - 一旦は、freeism向けに提供したいため
7. データ移行を簡単にしたい
   - インポート、エクスポートを簡単にできるようにしたい
8. OSSとしてすべてを公開

## 実装

- UIはリッチにしない
- 最低限の機能のみ
- 使用するライブラリやデプロイ環境は、他と一緒
- `points.freeism.app`に実装しているアカウント連携の機能は、`accounts.freeism.app`に移動させたい
