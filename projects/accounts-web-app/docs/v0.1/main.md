## 説明

- あらゆるアカウントのIDを統合して管理できるサービス

## 独立したサービスにする理由

1. アカウント統合の処理はとても複雑なので、責務の分離の為に切り出す
2. 他の無料主義サービスが、同じ内容を実装する必要がない状態にしたい
3. ポイント管理サービス以外からでも使用できると思う

## 要件

1. 第三者もアップロードできるようにする
2. 認証する
   1. OAuth認証
   2. `bi-directional link`
3. 閲覧権限の制御
   - 誰にデータの閲覧権限を渡してもよいのか
4. ドメインは、`accounts.freeism.app`
   - 一旦は、freeism向けに提供したいため
5. 他サービスからのインポート

## 実装

- UIはリッチにしない
- 最低限の機能のみ
