## 説明

- あらゆるアカウントのIDを統合して管理できるサービス

## 存在意義・独立したサービスにする理由

1. 無料主義の貢献度アップロードのアカウント管理を簡単にする
   - サービスの実装側・利用側の両方で、利用を簡単にしたい
2. アカウント統合の処理はとても複雑なので、責務の分離の為に切り出す
3. 他の無料主義サービスが、同じ内容を実装する必要がない状態にしたい
4. ポイント管理サービス以外からでも使用できると思う

## 存在意義の為に必要な機能・要件

1. アカウントのID
2. 第三者アップロード
3. 認証する
   1. OAuth認証
   2. bi-directional link
   3. メールアドレス認証
   4. 電話番号の認証（SMS認証）
   5. ドメイン認証
      - DNS TXTやHTMLタグ/ファイル**で所有を証明
4. 閲覧権限の制御
   - 誰に、どのデータの閲覧権限を渡してもよいのか
   - 連携したすべてのアカウントや情報を、それぞれのクライアントごとに公開するか決められるようにしたい
5. ドメインは、`accounts.freeism.app`
   - 一旦は、freeism向けに提供したいため
6. データ移行を簡単にしたい
   - インポート、エクスポートを簡単にできるようにしたい
7. Fediverseに対応
   - DID, ActivityPub, ATProtocolに対応
8. OSSとしてすべてを公開
9. あらゆる一致文言に対応
   - APIリクエストで、URLやユーザーIDなどいろいろな形式にするけど、その場合にいろいろな正規表現や条件分岐をして、なんとか探し出す処理にしておく
