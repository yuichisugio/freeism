# Accounts v0.2 実装計画

## JSONアップロードによるWeb URLの一括登録・一括検証

[v0.2仕様](../specification/v0.2/main.md#v02で追加する機能)に従って、次の順序で実装する。

1. JSON形式、一括処理の件数・容量上限、途中の失敗・回数制限・結果表示に関する要件を確定し、仕様書へ反映する。
2. v0.1のURL登録・正規化・ページ取得・所有権検証・認可・回数制限の処理を確認し、一括処理から共通の処理を呼び出す構成を設計する。
3. 確定した仕様から、JSON入力、複数URLの登録・検証、一意性、回数制限、途中の失敗、公開設定に関するテストを作成する。
4. JSONアップロード画面とバックエンドの一括処理を実装し、処理結果を本人が確認できる画面へ接続する。
5. 単件の登録・検証と一括処理の両方で、認可・所有権証明・公開条件が成立することを検証する。
