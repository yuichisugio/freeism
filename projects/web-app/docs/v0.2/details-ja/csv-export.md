## 概要

- `freeism-app v0.2`で実装するCSVエクスポート機能についての仕様
- `freeism-app v0.1`から大幅な仕様変更がある
- CSVエクスポートは、グループ管理者やアプリケーション所有者がグループ内のタスクデータや分析結果データをCSV形式でエクスポートするための機能を提供します。これにより、ユーザーはデータを外部ツールで分析したり、バックアップとして保存したりすることができます。

1. cc

## 具体的なエクスポートできる情報

### 方針

1. 自分が保有する権限で行える範囲で、`freeism-app v0.2`で設定できるすべてのデータをエクスポートできるようにしたい

### 具体的なデータ

1. プロフィールの情報すべて
2. 自分が評価軸オーナーの評価軸データ全て

## 権限

1. クライアントとサーバーの両方で権限チェックを行う。
2. CSVエクスポートできるのは、評価軸オーナーのみ
3. 評価軸オーナーのみ、CSVエクスポートできるボタンを表示するし、ボタンを押した際にも権限チェックする。バックエンドでも権限チェックする

## 概要

CSVエクスポートは、グループ内のタスクデータや分析結果データを CSV 形式で出力する機能です。ユーザーは出力したデータを外部ツールで分析したり、バックアップやレポート作成に利用できます。

## 用途

- タスク情報の一括エクスポート
- 分析結果データの一括エクスポート
- エクスポートしたデータの外部ツールでの分析
- データのバックアップ
- レポート作成

## 目的

- データの可視化と分析の促進
- 外部ツールとの連携の簡易化
- データのバックアップと保存
- レポート作成の効率化

## 権限

旧仕様上の権限:

- **グループオーナー**
  - 自身が所有するグループのデータのみエクスポート可能
  - グループ内のすべてのタスクと分析結果にアクセス可能
- **アプリケーションオーナー**
  - 全ての機能を利用可能
  - システム全体のあらゆるグループのデータにアクセス可能
  - 制限なしですべての操作が許可される
- **一般ユーザー**
  - アクセス不可
  - エクスポート機能へのアクセス自体が制限される
  - 権限不足時には適切なエラーメッセージを表示

現行実装上の表示条件:

- `GroupDetail` では、group member であればエクスポートボタンを表示します。
- owner 限定ではありません。
- CSVアップロードボタンは owner のみ表示します。

## 権限チェックロジック

旧仕様の権限チェックロジック:

1. セッションからユーザーIDを取得する。
2. アプリケーションオーナー権限を確認する。
   - ユーザーの `isAppOwner` フラグを検証する。
3. グループオーナー権限を確認する。
   - グループメンバーシップテーブルで owner 相当の権限を検証する。
4. いずれかの権限が確認できた場合のみ機能を有効化する。

現行実装では、上記の owner/app owner 限定チェックはエクスポート action 内では確認できません。現行仕様としては「group
member に表示される」を正とし、owner 限定へ戻す場合は実装変更が必要です。

## エクスポートタイプ

### `TASK`

グループ内のタスク情報を CSV 形式でエクスポートします。

エクスポート目的:

- `ANALYSIS`: 完了済みタスク、つまり `TASK_COMPLETED` のみを対象にします。
- `VIEWING`: すべてのステータスのタスクを対象にします。

### `ANALYTICS`

グループ内の貢献度評価結果を CSV 形式でエクスポートします。

フィルター:

- `onlyFixed = true`: `POINTS_AWARDED` のタスクのみを対象にします。
- `onlyFixed = false`: 固定済み以外も含む分析結果データを対象にします。

## タスクCSV

`exportGroupTask(groupId, startDate, endDate, onlyTaskCompleted)` が `cachedExportGroupTask` を呼び出します。

入力制約:

- 開始日と終了日が必須です。
- 開始日は未来不可です。
- 終了日は開始日以降です。
- 期間は最大6か月です。

抽出条件:

- `groupId`
- `createdAt` が開始日の startOfDay から終了日の endOfDay の範囲
- `ANALYSIS` の場合は `status = TASK_COMPLETED`
- 並び順は `createdAt desc`

エクスポートされるフィールド:

- `タスクID`: タスクの一意識別子
- `タスク内容`: タスクの詳細説明
- `参照`: 参考URLなどの外部リンク
- `証拠情報`: タスク完了の証拠となる情報
- `ステータス`: タスクの現在のステータス
- `貢献ポイント`: 固定された貢献ポイント値
- `評価者`: 固定評価者の ID
- `貢献タイプ`: `REWARD` または `NON_REWARD`
- `作成者`: タスク作成者の名前
- `報告者`: タスク報告者の名前。複数の場合はカンマ区切り
- `実行者`: タスク実行者の名前。複数の場合はカンマ区切り
- `作成日`: タスクの作成日。`YYYY-MM-DD` 形式
- `更新日`: タスクの最終更新日。`YYYY-MM-DD` 形式

データがない場合:

- `success: false`
- `message: "タスクが見つかりません"`
- `data: []`

ファイル名:

- `[グループ名]_tasks_analysis_[YYYYMMDD].csv`
- `[グループ名]_tasks_all_[YYYYMMDD].csv`

処理フロー:

1. 期間を指定する。
2. エクスポート目的を選択する。
3. サーバーへデータをリクエストする。
4. 取得データを CSV に変換する。
5. CSV ファイルをダウンロードする。

## 分析結果CSV

`exportGroupAnalytics(groupId, page, onlyFixed, onlyTaskCompleted)` が `cachedExportGroupAnalytics` を呼び出します。

入力・抽出条件:

- `page`: 取得ページ。UI候補は 1 から 5
- `limit`: 基本 200 件
- `onlyFixed = true` の場合は `POINTS_AWARDED`
- `onlyFixed = false` かつ `onlyTaskCompleted = true` の場合は `TASK_COMPLETED`

現行実装では、出力データは `Analytics` レコードそのものではなく `Task.fixed*`
も使います。固定評価済みのタスクは、評価者名ごとにグルーピングされます。

エクスポートされるフィールド:

- `分析ID`: 分析の一意識別子。現行実装では task id
- `タスクID`: 関連するタスクの一意識別子
- `貢献ポイント`: 付与された貢献ポイント
- `評価ロジック`: 評価の理由や根拠
- `評価者ID`: 評価者の一意識別子
- `評価者名`: 評価者の名前
- `タスク内容`: 評価対象タスクの詳細
- `参照情報`: 参考URLなどの外部リンク
- `証拠情報`: タスク完了の証拠情報
- `ステータス`: タスクの現在のステータス
- `貢献タイプ`: `REWARD` または `NON_REWARD`
- `タスク報告者`: タスク報告者の名前
- `タスク実行者`: タスク実行者の名前
- `タスク作成者`: タスクを作成したユーザーの名前
- `グループ目標`: 関連するグループの目標
- `評価方法`: グループで採用している評価方法
- `作成日`: 評価が行われた日付。現行実装では `fixedEvaluationDate` を使う
- `評価日`: FIX済みの場合のみ追加

処理フロー:

1. ページ番号を指定する。
2. FIX済みのみのオプションを選択する。
3. サーバーへデータをリクエストする。
4. 評価者ごとにデータをグループ化する。
5. 評価者が1人の場合は CSV、複数の場合は ZIP ファイルでダウンロードする。

制限事項:

- 1ページあたり200件のデータ制限
- UI上は最大5ページまでのページング
- 大量データの場合は複数回のエクスポートが必要

ファイル形式:

- 分析結果データ、評価者1人: 単一 CSV
- 分析結果データ、評価者複数: ZIP。評価者ごとの CSV を含める

ファイル名:

- `[グループ名]_analytics_[YYYYMMDD]_[評価者名].csv`
- `[グループ名]_analytics_[YYYYMMDD].zip`

## ユーザーインターフェース

### エクスポートボタン

表示位置:

- グループページのタスク一覧上部
- 右上のアクションエリア
- 他のアクションボタンと並べて表示

外観:

- アイコン: ダウンロードアイコン
- ラベル: 現行実装では「エクスポート」。旧仕様では「CSVエクスポート」
- 色: アプリのプライマリカラーまたは outline ボタン
- サイズ: 標準ボタンサイズ
- ホバー効果あり
- プレス効果あり

表示条件:

- 現行実装では group member に表示します。
- owner/app owner 限定にする場合は、旧仕様どおり権限がないユーザーには非表示にします。

アクセシビリティ:

- アイコンとテキストの組み合わせで識別しやすくする。
- `aria-label` で支援技術に対応する。
- 色だけでなく形状でも区別できるデザインにする。
- キーボードでフォーカスと操作ができるようにする。
- ハイコントラストモードでも視認性を確保する。

### ボタン動作

クリック時:

- エクスポートモーダルを開く。
- モーダル外クリックまたは閉じる操作でモーダルを閉じる。
- モーダル表示中は背景をオーバーレイで薄暗くする。

アニメーション:

- クリック時の軽いフィードバック
- モーダル開閉時のフェードイン/アウト
- 処理中のスピナー表示

エラー時:

- アクセス権限エラーは toast で表示する。
- サーバーエラーは toast で表示する。
- 回復可能なエラーはモーダル内表示またはリトライ導線を検討する。

## エクスポートモーダル

サイズ:

- 幅: 最大600px程度
- 高さ: コンテンツに合わせて可変。最大95vh
- モバイル画面では全画面に近い表示にする

構成:

- ヘッダー: タイトル「データをエクスポート」とグループ名
- ステッププログレス: 現在のステップを視覚的に表示
- コンテンツエリア: ステップごとの設定 UI
- フッター: 「前へ」「次へ」「エクスポート」などのアクションボタン

ステップ:

1. データタイプ選択
   - タスクデータ
   - 分析結果データ
2. 詳細条件指定
   - タスクデータの場合は期間指定
   - 分析結果データの場合はページ指定

## データ型選択ステップ

タスクデータカード:

- アイコン: ファイルアイコン
- タイトル: 「タスクデータ」
- 説明: タスクデータのエクスポート内容
- 選択時は青色の枠とハイライトで示す

分析結果データカード:

- アイコン: チャートアイコン
- タイトル: 「分析結果データ」
- 説明: 分析結果データのエクスポート内容
- 選択時は紫色の枠とハイライトで示す

タスクデータのエクスポート目的:

- 分析用: 完了済みタスクのみ
- 閲覧用: 全ステータスのタスク

分析結果データのフィルター:

- FIX済みのみ: チェックボックスで選択可能

## 期間指定ステップ

タスクデータでは期間を指定します。

日付選択 UI:

- 開始日選択: カレンダーピッカー
- 終了日選択: カレンダーピッカー
- 日付表示形式: `YYYY年MM月DD日`
- 無効な日付はグレーアウト

日付制約:

- 最大期間は6ヶ月
- 未来日付は選択不可
- 開始日が終了日より後の場合はエラー

期間サマリー:

- 選択した期間を「選択された期間: XXXX年XX月XX日 〜 XXXX年XX月XX日」のように表示する。
- 期間が不正な場合は続行不可にする。

## ページ指定ステップ

分析結果データではページを指定します。

ページ選択 UI:

- ドロップダウンで1から5ページを選択する。
- 各ページの範囲を `Nページ目 (X〜Y件)` と表示する。
- デフォルトは1ページ目。

ページサマリー:

- 選択したページを表示する。
- `onlyFixed` が有効な場合は「FIX済みの分析結果のみ」を表示する。

## エクスポート処理

処理表示:

- エクスポートボタンにスピナーを表示する。
- 「エクスポート中...」テキストを表示する。
- エクスポート中はボタンを無効化する。

完了通知:

- タスクデータ成功時: 「タスクデータを正常にエクスポートしました」
- 分析結果データ成功時: 「分析結果データを正常にエクスポートしました」
- エラー時: toast でエラーメッセージを表示する。

CSV/ZIP生成:

- PapaParse の `unparse` で JSON から CSV に変換する。
- Blob と `file-saver` でブラウザからダウンロードする。
- 複数評価者の分析結果は `fflate` の `zip` で ZIP ファイル化する。
- 現行実装の Blob type は `text/csv;charset=utf-8` です。旧仕様では BOM なし UTF-8 としていました。

## 技術仕様

### フロントエンド

- `ExportDataModal`
  - shadcn/ui の Dialog、Button、Calendar、Popover、RadioGroup、Select、Checkbox を使う。
  - lucide-react の Download、File、BarChart、Calendar などのアイコンを使う。
  - framer-motion でカード選択やステップ遷移のアニメーションを行う。
- `useExportDataModal`
  - export type、purpose、step、date、page、onlyFixed、exporting 状態を管理する。
  - date-fns で日付操作と日本語表示を行う。
  - PapaParse、fflate、file-saver で出力ファイルを生成する。

### バックエンド

- `exportGroupTask`
  - タスクデータをエクスポートする。
  - 実体は `cachedExportGroupTask`。
- `exportGroupAnalytics`
  - 分析結果データをエクスポートする。
  - 実体は `cachedExportGroupAnalytics`。
- Prisma クエリで関連エンティティを取得する。
- タスク、reporter、executor、creator、group、fixed evaluation 関連のデータを整形する。
- エラー時は `PromiseResult<T>` または例外で呼び出し元へ伝える。

## セキュリティ

アクセス制御:

- エクスポートボタンは group member に表示されます。
- action 内の明示的な owner/app owner 権限チェックは確認できないため、権限要件を変更する場合はサーバー側も更新します。

データ保護:

- センシティブデータを出力対象に含めない。
- ページングや期間指定でデータ量を制限する。
- ダウンロードファイルへのアクセスは、画面遷移と認証状態の前提に依存します。

エラー処理:

- 詳細なエラーメッセージはログに記録する。
- クライアントには一般化したエラーメッセージを表示する。
- スタックトレースをユーザーに表示しない。

## UIコンポーネント詳細

旧仕様で個別に記載されていた UI 部品の要件は、現行実装の `GroupDetail`、`ExportDataModal`、`useExportDataModal`
に対応する仕様として扱います。

### 起動ボタン

- Shadcn/UI の `Button` を使用します。
- lucide-react の Download 系アイコンを併用します。
- 旧仕様では `variant="default"`、`size="sm"`、青系の強調色、`aria-label="CSVデータのエクスポート"` を想定していました。
- 現行実装ではグループ詳細のアクション領域に「エクスポート」として表示されます。
- クリック時は export modal の open state を有効化します。

### ステッププログレス

- モーダル内では現在の入力ステップを視覚的に示します。
- ステップ数は2段階です。
  - データタイプ選択
  - 条件指定と実行
- 旧仕様では `StepCircle` と `StepLine` 相当の構成で、現在ステップと完了ステップの状態を分ける想定でした。
- 現行実装ではステップ遷移時に framer-motion のアニメーションを使います。

### アクションボタン

- 1ステップ目では次へ進む操作を提供します。
- 2ステップ目ではエクスポート実行ボタンを提供します。
- 戻る操作により1ステップ目へ戻れます。
- 実行中はボタンを disabled にし、ローディング表示を行います。
- 旧仕様では `ArrowLeft`、`ArrowRight`、`DownloadIcon`、`Loader2Icon` を使う想定でした。
- 現行実装でも lucide-react のアイコンと disabled state を使い、実行中の二重送信を防ぎます。

### モーダル内入力部品

- データタイプ選択は、ラジオ相当の UI として扱います。
- タスクデータの場合は開始日・終了日のカレンダー入力を表示します。
- 分析結果データの場合はページ選択と FIX済みのみのチェックを表示します。
- タスクデータでは分析用/閲覧用の目的選択を表示します。
- 選択値は hook の state に保持し、エクスポート処理の引数へ変換します。
