# v0.2.1 詳細仕様の編集

このフォルダの仕様を直すときは、次に従う。

## 文章

- 日本語の書き換えには yomiyasu スキルを使う。
- 仕様本文は、今の仕様だけを書く。

## 重複と不整合

- 同じ話題の重複、矛盾、不整合を見つけたら、一つにまとめる。
- 残すのは、各箇所にしかない要素だけである。同じ文は繰り返さない。
- まとめた結果は、話題ごとに一つの段落にする。
- 決めていない事実、手順、画面、APIは足さない。
- 決定が必要な場面では、それぞれの選択肢を選んだ際の懸念点も教えて欲しい

## v0.2.0との差

- v0.2.0と違う仕様にしたときは、この仕様書の末尾「v0.2.0からv0.2.1への変更」に箇条書きで足す。
- 本文には現行の仕様を書き、末尾の箇条書きに変更点を書く。
- v0.2.0より前の仕様書は書き換えない。
