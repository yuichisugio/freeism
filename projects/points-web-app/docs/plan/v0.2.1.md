## 概要

- 仕様は[v0.2.1の詳細仕様](../specification/v0.2.1/details/all.ja.md)を参照する。

- 依存を、仕様で使う機能に対応する版へ更新する。
  - Honoは、`app.query()`と`methodNotAllowed()`に対応する4.13以上へ更新する。
  - Better Authと`@better-auth/oauth-provider`は、OAuth Proxy経由のコールバックでの`iss`・nonceの検査と、`rotate-keys`に対応する1.7.12以上へ更新する。
  - TanStack Routerは、`navigate({ reloadDocument: true })`の遷移で離脱確認が二重にならない版へ更新する。
    - `@tanstack/react-router`は1.170.38以上、`router-core`は1.171.32以上とする。

- hono-openapiは、QUERYとOpenAPI 3.2への対応（上流のPR #303）がリリースされるまで、`pnpm patch`で修正を当てて使う。
  - npmの最新リリース1.5.0はQUERYの経路を出力から外す。
  - 当てる修正は、PR #303のうちQUERYの経路を出力する部分で、`ALLOWED_METHODS`に`QUERY`を足す1行である。
  - OpenAPI 3.2での出力は、`documentation.openapi`に`"3.2.0"`を指定して行う。
  - リリース後にpatchを外す。

- 実環境で次の動作を確かめる。
  - SPAモードで、存在しないJavaScript・CSSの要求に`index.html`が返ることと、`vite:preloadError`で画面を再読み込みすること。
  - stagingで、`ASSETS.fetch`を経由した要求にも`not_found_handling`が適用され、`index.html`が返ること。
  - `Cloudflare-Workers-Version-Overrides`が静的ファイルの要求にも効くか。
  - Cloudflare上で、QUERYの要求を送受信できること。
  - Better Auth 1.7.12で、`resources`の指定により`oauth_resource`の行が作られることと、`enforcePerClientResources: false`で`oauth_client_resource`の行なしに動作すること。

- 上記の版は2026-10-25に確認した。
  - 確認時点の最新版はhono 4.13.13、better-auth 1.7.12、hono-openapi 1.5.0である。
